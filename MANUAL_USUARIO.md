## PASO 1: CONOCER EL SISTEMA

### 1.1. ¿Qué es el Sistema?

Plataforma digital para registrarse, actualizar o renovar proveedores del gobierno de Oaxaca.

### 1.2. Roles de Usuario

**1.2.1. Usuarios Externos:**
- **Solicitante**: Solicitudes específicas
- **Proveedor**: Gestión completa de trámites

**1.2.2. Personal del Gobierno:**
- **Revisor Digital**: Revisa documentos
- **Revisor Presencial**: Cotejo presencial
- **Revisor Domiciliario**: Verificaciones domiciliarias

### 1.3. Requisitos y Documentos

**1.3.1. Técnicos:**
- Navegador actualizado (Chrome, Firefox, Safari, Edge)
- Internet estable
- JavaScript habilitado

**1.3.2. Documentos Obligatorios:**
- Constancia de Situación Fiscal del SAT con QR
- Identificación oficial vigente
- Comprobante de domicilio fiscal

**1.3.3. Adicionales:**
- **Persona Física**: CURP
- **Persona Moral**: Acta constitutiva, poder notarial

## PASO 4: INICIAR UN TRÁMITE

### 4.1. Tipos de Trámites

**4.1.1. Tres Opciones:**
- **INSCRIPCIÓN**: RFC nuevo → Obtiene número PV
- **ACTUALIZACIÓN**: RFC activo → Modifica información
- **RENOVACIÓN**: RFC próximo a vencer → Extiende vigencia

### 4.2. ¿Qué Trámite Realizar?

**4.2.1. El Sistema Evalúa:**
- RFC NO registrado → Solo INSCRIPCIÓN
- RFC registrado ACTIVO → Solo ACTUALIZACIÓN  
- RFC registrado VENCIDO → INSCRIPCIÓN o RENOVACIÓN
- Trámite EN PROCESO → No puede iniciar otro

[Insertar imagen: Pantalla de selección de trámites]

### 4.3. Iniciar Trámite

**4.3.1. Proceso:**
- Click "Nuevo Trámite" en dashboard
- Subir constancia fiscal actualizada (PDF con QR)
- Sistema extrae datos automáticamente
- Seleccionar tipo de trámite disponible
- Comenzar formulario con datos precargados
- [Insertar imagen: Carga de constancia en trámite]

### 4.4. Estados del Trámite

**4.4.1. Flujo:**
1. **En Proceso** → Completando formulario
2. **Enviado** → En cola para revisión
3. **Revisión Digital** → Evaluando documentos (3-5 días)
4. **Para Corrección** → Necesita cambios (5 días)
5. **Revisión Presencial** → Cita presencial
6. **Revisión Domiciliaria** → Inspección domicilio (7-10 días)
7. **Aprobado** → Completado exitosamente
8. **Rechazado** → No cumple requisitos

## PASO 5: COMPLETAR FORMULARIOS

### 5.1. Estructura General

**5.1.1. Proceso por Pasos:**
- Formulario dividido en secciones
- No puede avanzar sin completar sección actual
- Datos de constancia precargados
- Puede guardar y continuar después

### 5.2. Formulario Persona Física

**5.2.1. Secciones (4 + Términos):**
1. **Datos Generales**: RFC, nombre, CURP (precargados)
2. **Actividades Económicas**: Actividad principal y secundarias
3. **Domicilio Fiscal**: Dirección completa (precargada)
4. **Documentos**: Constancia SAT, INE, comprobante domicilio, CURP
5. **Términos y Condiciones**: Aceptación obligatoria

[Insertar imagen: Formulario persona física - vista general]

### 5.3. Formulario Persona Moral

**5.3.1. Secciones (7 + Términos):**
1. **Datos Generales**: RFC, razón social (precargados)
2. **Actividades Económicas**: Actividad principal y secundarias
3. **Domicilio Fiscal**: Dirección completa (precargada)
4. **Constitución**: Fecha, notario, escritura, objeto social
5. **Accionistas**: Lista y porcentajes (suma = 100%)
6. **Apoderado Legal**: Representante legal y facultades
7. **Documentos**: Acta constitutiva, poder notarial, identificación
8. **Términos y Condiciones**: Aceptación obligatoria

## PASO 6: ENVIAR Y HACER SEGUIMIENTO

### 6.1. Enviar Trámite

**6.1.1. Finalizar:**
- Completar todas las secciones
- Revisar información ingresada
- Aceptar términos y condiciones
- Click "Enviar Trámite"
- Recibir confirmación de envío

### 6.2. Estados del Trámite

**6.2.1. Seguimiento:**
- **Enviado** → En cola (0-1 día)
- **Revisión Digital** → Evaluando (3-5 días)
- **Para Corrección** → Necesita cambios (5 días límite)
- **Revisión Presencial/Domiciliaria** → Citas/inspecciones
- **Aprobado/Rechazado** → Resultado final

### 6.3. Consultar Progreso

**6.3.1. Opciones:**
- Dashboard: Ver estado actual
- Menú "Trámites": Historial completo
- Notificaciones: Cambios de estado
- Correo: Alertas importantes

## PASO 7: GESTIONAR CORRECCIONES

### 7.1. Identificar Correcciones

**7.1.1. Cuándo Ocurren:**
- Documentos no cumplen requisitos
- Información inconsistente
- Archivos no legibles
- Faltan datos obligatorios

**7.1.2. Notificación:**
- Alerta en dashboard
- Correo electrónico
- Especifica secciones a corregir
- Incluye comentarios del revisor

[Insertar imagen: Notificación de correcciones requeridas]

### 7.2. Realizar Correcciones

**7.2.1. Proceso:**
- Acceder al trámite en corrección
- Solo se muestran secciones señaladas
- Campos correctos bloqueados
- Modificar según comentarios
- Subir nuevos documentos si necesario
- Reenviar trámite

[Insertar imagen: Formulario en modo corrección]

### 7.3. Reenviar Trámite

**7.3.1. Límites:**
- Máximo 3 intentos de corrección
- Después del 3er intento puede ser rechazado
- Cada corrección reinicia el proceso
- Tiempo límite: 5 días para corregir

## ANEXOS

### Formatos y Requisitos Técnicos

**Documentos Aceptados:**
- Formato: PDF únicamente
- Tamaño máximo: 10MB por archivo
- Resolución mínima: 300 DPI para escaneados

**Requisitos del Sistema:**
- Navegadores: Chrome, Firefox, Safari, Edge
- Conexión: Banda ancha recomendada
- JavaScript: Debe estar habilitado

### Glosario de Términos

- **PV**: Proveedor Validado
- **RFC**: Registro Federal de Contribuyentes
- **CURP**: Clave Única de Registro de Población
- **SAT**: Servicio de Administración Tributaria
- **Constancia Fiscal**: Documento oficial del SAT con código QR
